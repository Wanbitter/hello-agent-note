配置环境与选择模型：为了让大多数读者都能在个人电脑上顺利运行，我们特意选择了一个小规模但功能强大的模型：Qwen/Qwen1.5-0.5B-Chat。这是一个由阿里巴巴达摩院开源的拥有约 5 亿参数的对话模型，它体积小、性能优异，非常适合入门学习和本地部署。
要安装这个东西哦：pip install transformers torch
这就装好了 3.2.3 需要的两个核心库：
transformers：Hugging Face 的模型加载库

torch：PyTorch，深度学习框架


记得在本地安装哦，就是在pycharm的控制台里安装，会安装到.env里，不会干扰本机环境
